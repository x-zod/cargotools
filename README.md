# 空运货代工具

纯前端单文件（`index.html`）空运货代日常询价报价工具，浏览器直接打开即可用，无需服务器、无需安装。数据默认存浏览器 LocalStorage，可选对接 Cloudflare Worker 做多设备同步；PC 与手机浏览器均已适配。

## 功能一览

### 1. 询价数据
- 粘贴客户询价文本，自动解析目的港三字码、件数、毛重、体积、尺寸；
- 自动算体积重、计费重、泡重比，支持尺寸批量反算体积；
- 自动匹配已导入航司表价，多服务段按当前命中档取最低主价（同价优先上海段），其余服务段与托盘价列参考；相邻比重档价格附在备注供参考；
- 支持相似历史询价参考、多票询价批量解析保存。

### 2. 报价记录
- 询价流水列表，按时间 / 状态 / 关键词筛选；
- 详情录入外配成本与客户卖价，自动算毛利；
- 可对单条记录重新匹配最新表价。

### 3. 航司表价
- **Excel 导入**：自动识别 45 / 100 / 300 / 500 / 1000KG 重量档，以及重货、泡货比重阶梯；Excel 组件按需懒加载（首次点导入时才拉取，平时不占体积）。
- **文字版识别**：直接粘贴微信 / 邮件里的文字表价，自动识别为统配表，支持多服务段（托盘 + 散货成对价）、多目的港逐港价（共享泡货阶梯自动按规则挂港）、手写版整批更新（自动过期旧版）。
- **航司自动识别**：粘贴文字时自动判断航司和中转点，可手动改。
- **新旧对比弹窗**：打开表价详情时自动找上一版，每档涨跌标注（涨红 ↑N、跌绿 ↓N），持平不标；顶部提示条"与上一版（xxx date）对比：涨跌已标注"。
- **自动过期**：同航司 + 中转点的新表导入后，旧版自动标记过期（不再参与询价匹配，但保留在列表里可回看、可对比）。
- 截图存证、限时调价、手动恢复 / 删除管理。
- 内置业务规则：各航司转运费、中转区域加价、卡车二程联动、重量门槛与比重减价、限重提示等。

### 4. 成本计算
- 批量尺寸录入自动汇总总体积；
- 计费模式：大陆 1:167 / 香港 1:143 / 快件 1:200 / 海运 1:1000；
- 分泡：不分泡 / 55 分 / 46 分 / 37 分 / 28 分；
- USD-RMB 汇率换算：输入 RMB 自动清 USD、输入 USD 自动清 RMB（正算 / 反算互斥，不会串值）；
- 输入成本单价得分泡后单价（RMB / USD），输入目标售价反算可承受成本；输出总成本 RMB / USD。

### 5. 后台管理
- JSON 完整备份 / 恢复；询价与表价导出 CSV；
- **多设备云同步**（可选 Cloudflare Worker）：
  - 软删除 + 墓碑机制（删除后 90 天内不同步复活，超期自动清理）；
  - LWW（最后写入胜出）合并：多端同时编辑时按 updatedAt 时间戳取最新，本地新增不会被云端旧数据误盖；
  - 保存按钮防抖锁（1 秒内重复点不触发两次）。
- 简易记录统计。

## 使用方式

**在线（GitHub Pages）**
1. 仓库只保留 `index.html`；
2. 仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后获得访问链接。
   > Pages 仅托管页面；云同步仍需自行部署 Worker，不部署则全部为本地存储。

**本地离线**
1. 下载 `index.html`，用 Chrome / Edge 直接打开；
2. Excel 解析与云同步需联网，其余功能离线可用。

## 数据说明
- 数据默认保存在浏览器 LocalStorage；清除缓存 / 无痕模式会丢失，**请定期导出 JSON 备份**；
- 不建议在微信内置浏览器打开（部分环境限制 LocalStorage）；
- 可选云同步需自行部署 `cloudflare-worker.js`，在后台填入地址与账号后启用。
