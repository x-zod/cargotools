# ✈️ 空运货代工具
> 纯前端本地空运货代业务工具，浏览器直接运行，无需服务器、无需安装软件。
> 数据默认存储浏览器 LocalStorage，支持 JSON备份恢复 / CSV导出分析 / Cloudflare Worker云同步。
> 📱 已做移动端适配，PC、手机浏览器均可操作。

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-在线体验-green)](https://x-zod.github.io/cargotools/)



## 📋 功能简介
专为空运货代日常询价报价打造，整合询价文本自动解析、报价管理、航司表价管理、成本计算器。

### 🔹 询价数据
- 粘贴客户询价文本**AI式自动解析**：目的港IATA三字码、件数、毛重、体积、尺寸；
- 自动计算：体积重、计费重、泡重比；支持尺寸自动反算体积；
- 智能参考：
  - 相似历史询价：同目的港、计费重/泡重比接近的历史报价；
  - 航司表价自动匹配（内置LH转运费、AA128中转加价业务规则）；
  - 历史外配成本一键填入；
- 支持**多票询价一次性解析保存**。

### 🔹 报价记录
- 全部询价流水列表；支持按时间、报价状态、关键词搜索筛选；
- 详情弹窗：录入外配供应商成本、客户卖价，自动计算毛利；
- 查看同规格历史价格记录；支持重新匹配最新航司表价。

### 🔹 航司表价管理
- Excel导入航司牌价，自动过滤灰色无效价格，识别45/100/300/500/1000KG重量档，支持重货/泡货比重档位；
- 支持粘贴文字版表价识别、手动录入、截图存证；
- 航司限时调价功能（设置加减价、到期时间）；
- LH内置FRA hub转运附加费；AA128中转区域加价逻辑；
- 快速查询目的港表价，附带机场中文名称；
- 表价过期/恢复、删除管理。

### 🔹 成本计算
专业空运成本计算器
- 批量尺寸输入自动计算总体积；
- 计费模式切换：大陆1:167 / 香港1:143 / 快件1:200 / 海运1:1000；
- 分泡：不分泡、55分、46分、37分、28分；
- USD‑RMB汇率，RMB/USD双向换算；
- 支持：输入成本反推售价 / 输入目标售价反推可承受成本；
- 输出：计费重、分泡后单价、总成本人民币/美元。

### 🔹 后台管理
1. **数据备份恢复**：导出完整JSON备份、从备份文件恢复；
2. **导出CSV**：询价记录、航司表价长表，可用于Excel/Python数据分析；
3. **云同步（可选）**：对接Cloudflare Worker实现多设备双向数据同步；
4. 简易业务统计：总记录、已报价、未报价数量。

## 🚀 快速使用
### 方式1：GitHub Pages在线使用（推荐）
1. 将本仓库fork或者上传代码，仓库里面只保留 `index.html`；
2. 仓库设置 → Pages → Source选择 `main`分支 `/root`；
3. 保存，等待部署完成，即可获得公开在线访问链接。

> ⚠️ 注意：GitHub Pages**仅提供页面访问**，云同步功能仍然需要你自己部署Cloudflare Worker后端，不部署Worker就全部为浏览器本地存储。

### 方式2：本地离线使用
1. 下载仓库中 `index.html` 文件；
2. 直接双击用Chrome / Edge / Safari浏览器打开即可；
3. ✅ 完全离线，不需要网络（仅Excel解析、云同步需要联网）。

> ❗ 重要提醒：
> - 所有数据默认保存在**浏览器本地LocalStorage**；清除浏览器缓存/无痕模式会丢失数据；**务必定期导出JSON备份**；
> - 不建议把html文件放到微信内置浏览器打开，部分浏览器会限制localStorage。

## ☁️ 云同步（可选高级功能）
> 默认关闭，不配置Worker就只用本地存储。
1. 需要自行部署配套 Cloudflare Worker，提供API接口；
2. 在页面后台管理填入Worker地址、用户名密码，执行双向同步；
3. 多台设备浏览器登录同一个账号，完成询价+表价+调价记录同步。

> Worker代码不在本仓库内，如果你需要可以单独索要。
