# 空运货代询价报价工具

一个**单文件**的空运货代工作台：`index.html` 双击即用，不依赖服务器、不需要安装。覆盖「客户询价解析 → 表价匹配 → 报价记录 → 成本核算 → 数据备份 / 多设备同步」的日常闭环，PC 与手机浏览器都已适配。

> 仓库只放工具代码。**不含任何真实运价、承运方名称、航点清单或加价规则**；表价由使用者在工具内自行导入，业务规则随表价版本在本地维护。

## 快速开始

### 在线使用（GitHub Pages）

1. 仓库根目录只保留 `index.html`（其余目录不必上传）；
2. Settings → Pages → Source 选 `main` 分支根目录，保存后即得访问链接；
3. 页面本身是纯静态托管，云同步需要另外自建后端，不部署则全部本地存储。

### 本地离线

1. 下载 `index.html`，用 Chrome / Edge 直接打开（也可放 U 盘随身带）；
2. 除「Excel 解析」「云同步」需要联网外，其余功能离线可用；
3. 建议固定放在同一路径，浏览器按文件地址区分 LocalStorage，换路径会读不到旧数据（先导出 JSON 再迁移）。

## 功能说明

### 1. 询价数据

- 粘贴客户询价原文，自动识别目的港三字码、件数、毛重、体积、尺寸，兼容中英文混排与大小写；
- 自动计算体积重、计费重、泡重比；支持逐件尺寸录入并反算总体积；
- 自动在已导入表价里匹配：多服务段按命中档取最低主价，同价时优先起运地直发段，其余服务段与托盘价并列参考；相邻比重档的价格附在备注里备选；
- 同一票可查相似历史询价（同目的港 / 同重量档）作为报价依据；
- 支持一次粘贴多票，批量解析后统一保存，避免逐票重复录入。

### 2. 报价记录

- 流水列表支持按时间范围、状态、关键词（目的港 / 客户 / 备注）组合筛选；
- 手机端为两行紧凑卡片：第一行「日期 · 目的港 · 表价」，第二行「件数 / 毛重 / 体积 + 详情管理」，点整卡进入详情；桌面端保留完整表格；
- 详情管理内可完成：改货量（件数 / 毛重 / 体积 / 日期 / 备注，保存后自动重算计费重与泡重比并重新匹配表价）、重新匹配最新表价、录入外配成本与客户卖价、实时毛利（单公斤与整票）、转入成本计算、删除记录；
- 支持在「后台管理」统一导出 CSV，便于对账或交接。

### 3. 表价管理

- **Excel 导入**：按表头锚点识别 45 / 100 / 300 / 500 / 1000KG 重量档与重货、泡货比重阶梯，容忍合并单元格、错位列与备注列；解析组件按需懒加载，首次点导入才拉取，平时不占加载时间；
- **文字版识别**：直接粘贴聊天 / 邮件里的表价文本，自动识别为统配表；支持多服务段（托盘 + 散货成对价）、逐港价、整批手写版更新；
- **来源与中转点**：粘贴时自动判断表价所属来源与中转点，识别错误可手动修正；
- **新旧对比**：打开表价详情自动找上一版，逐档标注涨跌（涨 ↑、跌 ↓、持平不标），顶部给出对比提示；
- **自动过期**：同来源 + 同中转点导入新表后，旧表自动转过期，不再参与匹配，但保留可回看、可对比；
- **归档区**：过期表价折叠收纳，按来源分组、标题置灰，点开才展开；
- 另有限时调价、手动恢复 / 删除等管理动作。

### 4. 成本计算

- 批量录入尺寸，自动汇总总体积；
- 计费模式：大陆 1:167 / 香港 1:143 / 快件 1:200 / 海运 1:1000，选项等宽排列；
- 分泡比例：不分泡 / 55 分 / 46 分 / 37 分 / 28 分；
- 汇率换算双向互斥：填 RMB 自动清 USD，填 USD 自动清 RMB，不会串值；
- 已知成本单价 → 得分泡后单价与总成本；已知目标售价 → 反算可承受成本。

### 5. 后台管理

- JSON 全量备份 / 恢复（含询价、表价、调价记录、同步配置）；
- 询价与表价导出 CSV；
- 可选云同步配置、数据保留策略（默认不自动清理，可选保留 1 年 / 2 年）；
- 记录数量与容量概览。

## 稳定性设计

- **全量转义**：所有用户输入进入页面前统一 HTML 转义，避免粘贴内容破坏页面或注入脚本；
- **本地时区**：日期按本地时区拼接，跨时区 / UTC 环境下不会出现"差一天"；
- **存储配额保护**：写入超限时先清理过期删除标记再重试，仍失败只提示、不丢当前内存数据；
- **解析超时**：Excel 解析设超时上限，异常表格不会卡死页面；
- **快捷键**：`Ctrl / Cmd + Enter` 直接提交当前表单；
- **强制刷新**：刷新按钮带时间戳参数，绕过浏览器缓存，拉取最新版本页面；
- **同步互斥**：同一轮双向同步加锁，避免连点造成重复请求；一次同步的请求数已压到最少；
- **弱网与空数据保护**：云端返回空数组不会覆盖本地数据；同步失败显示黄点、成功显示绿点；
- **多标签页一致**：任一标签页写入后，其他标签页自动失效缓存并重绘；
- **回到前台自动拉取**：页面重新可见且距上次同步超过阈值时静默同步，不打断操作。

## 数据存储与备份

| 存储键 | 内容 | 说明 |
| --- | --- | --- |
| `af_inquiries_v1` | 询价 / 报价记录 | 含软删除标记，用于多端同步 |
| `af_rate_sheets_v1` | 已导入表价 | 含过期归档与表价备注 |
| `af_adjustments_v1` | 限时调价记录 | 按表价 + 生效区间叠加 |
| `af_sync_config` | 云同步配置 | 地址与访问口令，仅存本机 |
| `af_retention_years` | 保留策略 | 0 = 不清理，1 / 2 年可选 |

- 数据默认只在本机浏览器，**清缓存、换浏览器、无痕模式都会丢**，请定期导出 JSON；
- 容量上限约 5MB（浏览器限制），表价历史过多时优先清理过期表或按需导出备份；
- 微信内置浏览器对 LocalStorage 支持不稳定，建议用系统浏览器或桌面端打开。

## 可选：多设备云同步

1. 自行部署一个轻量后端（Cloudflare Worker + KV 即可），实现三个集合的读写接口；
2. 在「后台管理」填入自己的地址与访问口令，点击测试连接；
3. 同步策略：
   - **LWW 合并**：按 `updatedAt` 取最新，本地新增不会被云端旧数据覆盖；
   - **软删除 + 墓碑**：删除后保留 90 天标记，避免另一台设备把已删记录同步回来；超期自动清理；
   - **统一回写**：一次拉齐三个集合并合并后统一推送，避免各集合各自触发同步造成重复请求。

> 不部署后端时，工具完全离线可用，所有功能不受影响。

## 常见问题

**Q：打开是一片空白 / 数据不见了？**
A：先确认是否换了文件路径或换了浏览器（LocalStorage 按来源隔离）；用「后台管理 → 恢复 JSON」导入最近备份。

**Q：表价导入后询价匹配不到？**
A：检查表价是否已过期（新表导入会自动把旧表转过期）、目的港与中转点是否在该表覆盖范围内、重量档是否落在表价区间。

**Q：手机上按钮或输入框超出屏幕？**
A：确认浏览器缩放为 100%；已按 390–500px 宽度适配，若仍有溢出请附截图反馈。

**Q：同步一直黄点？**
A：检查后端地址与口令、网络是否可达；失败不会影响本地使用，恢复后下次同步自动补齐。
